# Architecture Decision Records — Point Barbershop

> Repo path: `docs/adr/`. One file per decision, numbered, never deleted — a reversed decision gets a new ADR that marks the old one *Superseded*. Format = `engineering:architecture` ADR template (Status / Context / Decision / Options with Complexity · Cost · Scalability · Team-familiarity / Trade-offs / Consequences / Action items). Each file starts with a Myanmar summary for the owner.
> Status rule (🔒 D-PLT-11): **Accepted** = covered by a 🔒 decision in the review's Appendix A or decided by the owner in chat; **Proposed** = ⚠️ recommendation, binding only after the owner says "OK"; **Superseded** = replaced by a newer ADR (kept for history). A change that keeps the decision is written **in place** as a dated *Amendment* (status stays Accepted) — e.g. ADR-011 #7 (→ ADR-012) and ADR-012 Amendment 1.
